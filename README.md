# n8n Automation Lab

A practical collection of automation patterns using n8n, databases, APIs, notifications and scheduled workflows.

## Focus

- Scheduled jobs
- SQL Server integration
- Reporting automation
- Notifications
- Data quality checks
- API integrations
- Healthcare IT automation patterns

## Structure

- `workflows/`
- `database/`
- `notifications/`
- `reporting/`
- `integrations/`

## Design Principles

Simple, observable, secure and maintainable workflows.

Credentials and real production connection details are never committed.
